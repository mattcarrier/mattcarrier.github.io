Jarvis

A personal knowledge agent. One operator, one machine, no third parties.

Jarvis is a private assistant that maintains a searchable record of its operator's own working life — correspondence, commitments, meetings, projects, and the people attached to them — so that context does not have to be re-explained from memory every time it is needed.

It is not a product, a service, or a hosted platform. It is a single-user application run by one person on their own hardware, built on the open-source gbrain knowledge-base runtime. There are no accounts to create and nothing to sign up for.

What it connects to

With the operator's explicit consent, Jarvis reads three Google services on a read-only basis:

  • Gmail — so that threads become searchable pages and open commitments can be surfaced
  • Google Calendar — so that events carry their attendees, locations, and preparation context
  • Google Contacts — so that senders and attendees resolve to the right people

Jarvis never writes to, modifies, or deletes anything in a Google account. The permissions it requests do not permit it to.

Where the data lives

Everything Jarvis reads is stored locally, in a database on the operator's own machine. Nothing is transmitted to Jarvis's developer, uploaded to a hosted service, sold, or shared. Access tokens are held in a local credential vault readable only by the operator's user account.
