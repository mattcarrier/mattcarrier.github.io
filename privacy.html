Privacy Policy

Jarvis · Effective 1 September 2026

Jarvis is a single-user personal knowledge agent operated by one individual on their own hardware. It is not offered to the public as a product or service. This policy describes what data the application accesses, why, where it is stored, and how access is withdrawn.

Who this covers

The only user of this application is its operator. No other person's Google account is connected to it, and the application does not collect data from visitors to this website. This site serves two static pages and sets no cookies, runs no analytics, and embeds no third-party scripts or fonts.

Google user data accessed

With the operator's explicit OAuth consent, the application requests these scopes, all of which are read-only:

  • openid and email — to identify which Google account the stored credential belongs to
  • gmail.readonly — to read message and thread content so it becomes searchable and so outstanding commitments can be surfaced
  • calendar.readonly — to read events, times, locations, and attendees
  • contacts.readonly — to resolve senders and attendees to the correct people
The application holds no write, modify, send, or delete permission for any Google service. It is technically incapable of altering the contents of the connected account.

Why it is accessed

Solely to build and maintain the operator's own private, searchable record of their correspondence, schedule, and contacts. The data is not used for advertising, profiling, resale, market research, model training, or any purpose beyond serving the operator directly.

How it is stored

  • Message, event, and contact content is stored in a database on the operator's own machine. It is not uploaded to any hosted service.
  • OAuth access and refresh tokens are stored in a local credential file readable only by the operator's own user account.
  • No copy of any of it is transmitted to the application's developer, because there is no server to transmit it to.

Sharing and disclosure

Google user data is never sold, rented, traded, or transferred to any third party. It is not shared with advertisers, data brokers, or analytics providers. No human other than the operator has access to it.

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Data is retained locally for as long as the operator finds it useful, and is deleted whenever they choose to delete it. Because storage is local, deletion is complete and immediate — removing the local database removes every copy.

Revoking access

The operator may revoke this application's access at any time at myaccount.google.com/permissions. Revocation immediately invalidates the stored tokens and halts all further reading. Any data already stored locally is then removed by deleting the local database.

Security

Credentials are stored with owner-only file permissions on an operator-controlled machine and are never committed to source control. The application communicates with Google over TLS. Because it exposes no public network service, there is no remote attack surface reachable by third parties.

Children

This application is not directed at children and is used only by its adult operator.

Changes

If this policy changes, the revised version is published on this page with an updated effective date.
